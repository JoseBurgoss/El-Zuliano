# El Zuliano

Plataforma web de noticias con registro de usuarios, suscripciones, integración con redes sociales, filtros por categoría y una experiencia de lectura responsiva.

News platform with user registration, subscriptions, social media integration, category filters and a responsive reading experience.

🔗 **Live demo:** https://el-zuliano.vercel.app

## 🇪🇸 Español

### Descripción
El Zuliano es una aplicación web de noticias construida con **React** y **Vite**. Incluye autenticación de usuarios, suscripciones, personalización de contenido, filtros avanzados por categoría y diseño optimizado para SEO.

### Características
- Registro e inicio de sesión de usuarios
- Sistema de suscripción
- Noticias por categorías con filtros y búsqueda
- Integración con redes sociales
- Actualizaciones y contenido personalizado
- Diseño responsivo (móvil, tablet y escritorio)
- Optimización SEO (React Helmet)

### Stack
- **Frontend:** React 18, JavaScript, HTML5, CSS3
- **Build tool:** Vite
- **Rutas:** React Router v6
- **UI/Animación:** Framer Motion, react-alice-carousel
- **HTTP:** Axios
- **SEO:** React Helmet

### Cómo ejecutarlo
```bash
cd El-Zuliano
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción
npm run preview  # previsualizar el build
```

## 🇬🇧 English

### Overview
El Zuliano is a news web application built with **React** and **Vite**. It features user authentication, subscriptions, content personalization, advanced category filtering and SEO-friendly, responsive design.

### Features
- User registration and login
- Subscription system
- News by category with filters and search
- Social media integration
- Personalized content and updates
- Fully responsive design
- SEO optimization (React Helmet)

### Tech stack
- **Frontend:** React 18, JavaScript, HTML5, CSS3
- **Build tool:** Vite
- **Routing:** React Router v6
- **UI/Animation:** Framer Motion, react-alice-carousel
- **HTTP:** Axios
- **SEO:** React Helmet

### Getting started
```bash
cd El-Zuliano
npm install
npm run dev
```
